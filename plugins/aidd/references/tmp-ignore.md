# `tmp/`・`tmp.md` の除外の確かめ方

スキルが `tmp/` や `tmp.md` に書く前に、`.gitignore` で除外されているかを確かめる。除外されていなくても書いてよいが、下書きがコミットに混ざらないよう利用者に伝え、利用者の `tmp.md` を無断で上書きしないため。

## 確かめる場合

- `git check-ignore tmp/ tmp.md` を実行する。除外されているパスだけが出力に出る
- どちらも除外されていないと、終了コードは 1 になる。失敗ではないため、出力が空として扱う
- 確かめられないとき（終了コード 128 など）は、除外されていないとして扱う

## 除外されていない場合

- 止めずに書く。結果を伝えるときに、「`.gitignore` に `tmp/` と `tmp.md` を足すと、コミットに混ざらない」と 1 行添える。`.gitignore` は利用者が直し、Claude は足さない
- `tmp.md` が既にあり中身があれば、上書きする前に中身を見せ、上書きするかを聞く。利用者が別の用途で使っているおそれがあるため
- `git status` に出る `tmp/`・`tmp.md` は、作業中の変更として扱わない。スキルの前回の出力のため
