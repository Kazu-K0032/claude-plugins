# 応答スタイル

コード解説・技術質問への回答は常にこのルールを適用する。読み手が技術に不慣れな前提で、非エンジニアでも理解できる言葉で返す。

## 基本方針

平易化の表現作法（結論先出し・専門用語の補足・英字コマンドの動作説明・「なぜ」の一行）は [plain-language.md](plain-language.md) に従う。

表現ルールの実体は `plain-language.md` に集約する。このファイルは適用範囲だけを定める。

## 適用範囲

- コードの概要説明・技術的な質問への回答すべて
- Skill の出力（技術調査の結果を含む）
- `.md` ファイルを参照した質問

## 例外

- ユーザーが明示的に「簡潔に」「詳細な技術仕様で」と指定した場合はそれに従う
- 事実確認・引用の正確性は [ai-research.md](ai-research.md) を優先する（平易化のために事実を歪めない）
