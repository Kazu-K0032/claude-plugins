# 止まるとき・エラーのとき（docs-sync）

手順 2 のスクリプトが `STOP`・`ERROR` を返したとき、終了コードの意味を確かめるときに読む。

## 停止するブランチ

基準ブランチは、今のブランチのマージ先（決め方は `SKILL.md` の手順 1）。マージ先が今のブランチ自身になるとき（既定ブランチで実行したときなど）と、`main`・`master` では、差分の基準が無いため停止する。

- `develop` のように、ほかのブランチのマージ先になるブランチでも、自分のマージ先（`stg`・`main` など）があれば止めない。リリース前に、未リリースの変更へドキュメントが追従しているかを点検できるようにするため

## スクリプトの終了コード

| 終了コード | 表示 | 意味 | 次の動き |
| --- | --- | --- | --- |
| 0 | なし | 機械チェックがすべて PASS | 手順 3 へ進む |
| 1 | なし | 機械チェックに FAIL がある | 手順 3 へ進む。FAIL でも手順 3 を省かない |
| 2 | `ERROR` | `--base` のブランチが見つからないなど | 以降を行わず、渡したブランチと原因をユーザーに伝えて終わる |
| 3 | `STOP` | 基準ブランチ上で実行した | 以降を行わず、停止の理由をユーザーに伝えて終わる。レポートは作らない |
