# 既存の判断を変更する手順

リリース後の問題や状況の変化で、既存 ADR の判断を変えるときの手順。旧 ADR の本文は書き換えず、新しい ADR を足して履歴として残す。`SKILL.md` の手順 4 で、既存の判断を変えるときに読む。

1. 置き換え対象の旧 ADR を Read し、何を決めていたかを確認する
1. `SKILL.md` の手順 3 に従って新 ADR を作る
   - ファイル名は旧 ADR と同じ判断の対象名にする（例：旧 `2026-04-10-session-storage.md` → 新 `2026-09-30-session-storage.md`）
   - 判断の種類は「既存の判断の変更」にし、背景に元の判断と変える必要が出た経緯を書く
   - 置き換える旧 ADR への相対リンクを書く（詳細版は「関連情報」の「置き換える ADR」）。きっかけになった障害報告・作業ログ・Issue があれば「経緯の記録」にリンクする
1. 旧 ADR の `status` を `[YYYY-MM-DD-subject](YYYY-MM-DD-subject.md) により置き換え済み` に変更する（新 ADR への相対パスリンクを必ず含める）。本文への追記は一切しない
1. 一覧に新 ADR の行を足し、旧 ADR の状態の列も合わせる

新規作成と同じく、旧 ADR の status の変更も含めて、「ADR にするかを聞く」で選んでもらってから行う。
