# 中断するとき・更新せずに終えるとき（issue-pr-sync）

手順 1 で Issue・PR が取れなかったとき、PR が閉じていたとき、手順 3 で根幹が変わっている・更新が要らないと判断したときに読む。

## 中断する

- `gh issue view` / `gh pr view` が失敗したら、その時点で中断して原因を報告する（存在しない・権限が無い・リポジトリが違う）
- PR を省いたのに今のブランチに PR が無ければ中断し、PR を作ってから実行するか、PR の識別子を渡すよう伝える
- PR が `merged` / `closed` の場合は何も変更せず、理由を報告して終わる
- 根幹が間違っている（目的そのものが変わった）と判断したら、追従ではなく作り直しのため、その旨を報告して中断する

## 更新せずに終える

差分が空、またはレビュー指摘が無く、既存の本文・タイトル・サイドバーと実態が一致している場合は、「更新不要」と報告して終わる。形だけの更新を作らない。

ただし、本文が 500 文字を超えていれば縮め、「AI を使った確認」の自分の行に番号やチェックの不足があれば直す。その分だけ反映してから終わる。
