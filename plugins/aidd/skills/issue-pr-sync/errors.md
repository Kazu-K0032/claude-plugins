# 反映せずに終わるとき・変更を作らないとき

`issue-pr-sync` で、追従ではなく作り直しになるとき、更新が要らないとき、PR が閉じているときの扱い。

## 反映せずに終わる場合

- 根幹が間違っている（目的そのものが変わった）と判断したら、追従ではなく作り直しなので、その旨を報告して中断する
- 差分が空、またはレビュー指摘が無く既存本文・タイトル・サイドバーと実態が一致している場合は「更新不要」と報告して終わる。形だけの更新を作らない。ただし、本文が 500 文字を超えていれば縮め、「AI を使った確認」の自分の行に番号やチェックの不足があれば直す。その分だけ反映してから終わる
- PR が `merged` / `closed` の場合は何も変更せず、理由を報告して終わる

## 変更を作らない対象があるとき（手順 3）

更新が不要と判断した対象があれば、無理に変更を作らず「変更なし」とする。ただし、次の 2 つは変更として作る。

- 本文が 500 文字を超えているとき：縮める変更
- PR 本文の「AI を使った確認」の自分の行に、番号の不足やチェックの不足があるとき：その分の変更
