# 出力テンプレート

`pr-check` Skill が `tmp/<ブランチ名>/pr-check_<yyyymmdd_hhmmss>.md` に書き出すレポート構造を定義する。

````markdown
## PR-Issue紐づきチェック結果

### ✅ 実装完了項目

- [タスク1]: [実装内容の詳細]

### ⚠️ 部分実装項目

- [タスク3]: [実装済み部分] / [未実装部分]

### ❌ 未実装項目

- [タスク4]: [未実装の理由・対応が必要な内容]

### 📋 完全性チェック

- **実装の完全性**: [部分実装・TODO の有無]
- **テスト**: [有無と追加推奨事項]
- **ドキュメント**: [更新状況と追加推奨事項]

### 🔍 成果物別の整合（該当する場合）

- [対象種別]: [規約との整合・気づき]

### 🎯 総合評価

[要件達成度とマージ可否の判断。網羅的なコードレビューが必要ならその旨を案内]
````
