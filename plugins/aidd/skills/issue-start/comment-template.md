# Issue へのコメントのテンプレート

`issue-start` が着手を見送ったときに、ユーザーが選んだときだけ Issue に投稿するコメントの形を決める。形を変えたいときは、このファイルを直す。

## 書き方

- 1 文・1 項目は 50 文字以内、全体は 500 文字以内にする（数え方は `references/short-body.md`）。確かめた経緯は書かず、結論と確かめた先（`<ファイル>:<行>` や URL）だけを書く
- 中身が無い節は見出しごと消す。テンプレートに無い節は足さない
- 報告にある「合っていたこと」は載せない。Issue を読む人が次に動くのに要らないため

## 着手を見送った理由

判定が「前提が崩れている」で、ユーザーが「Issue にコメントして終わる」を選んだときに使う。

```markdown
## 着手を見送った理由

`/aidd:issue-start` で今のコードと突き合わせ、前提が崩れていると分かった。

- <当たった止める基準と、確かめた先>

### 着手するには

- <Issue をどう直せば着手できるか>
```
