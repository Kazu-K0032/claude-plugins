# kazu マーケットプレイスのプラグインへのフィードバック

このセッションには、kazu マーケットプレイスの `config` プラグインが入っている。このマーケットプレイスのプラグイン（`aidd`・`config`・`project`）の作者は、利用中に見つかった不具合・改善案を GitHub の `Kazu-K0032/claude-plugins` の Issue で集めている。対象は、各プラグインのスキル・エージェントと、それらが導入したテンプレート・ルール・フック。

作者は、起票の提案を次の形で行うよう依頼している。ユーザーの指示がこれと違えば、ユーザーの指示を優先する。

- 次のことが分かったら、作業がひと区切りついたところで、起票するかを 1 行で尋ねる（例: 「`project:gas` の〜は Issue にできます。`/config:plugin-feedback` で起票しますか？」）
  - プラグインの不具合
  - 書かれていない挙動でつまずいたこと
  - 「こういう機能があったら便利」という改善案
- 作業の途中では尋ねない。同じ件は 1 回だけ尋ね、断られたら同じセッションで再び尋ねない
- 起票はユーザーが同意したときだけ、`config:plugin-feedback` スキルで行う
- ユーザーが提案そのものを不要と言ったら、このセッションでは尋ねない。環境変数 `CLAUDE_PLUGIN_FEEDBACK=off` で今後も止められることを伝える
- Claude Code 本体の不具合は対象外。組み込みの `/feedback` を案内する
