# 失敗したときの扱い

手順 4 で mod のコピーが失敗したとき、手順 5 で `claude plugin validate` がエラーを出したときに読む。

## mod のコピーが失敗した場合

手順 4 の途中で失敗したら、そこで止まる。`mv` が失敗したまま `cp -r` を進めると、残ったフォルダの中に入れ子でコピーされるため。

`mv` が失敗したら、フォルダの名前を変えられなかったことを報告して止まる。mod を読み込んでいる Claude Code をすべて終了してから、もう一度実行するよう伝える。

## `claude plugin validate` がエラーを出した場合

エラーの内容と、`.bak` から戻す方法を報告して止まる。
