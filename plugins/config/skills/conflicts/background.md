# 設定のスコープと、標準の `/doctor` との違い

conflicts スキルの背景。

Claude Code の設定はスコープ（managed / local / project / user）ごとに分かれ、上位のスコープが下位を上書きする。配列（権限ルール・フック）はスコープ間で結合される。このため「書いたのに効かない」「同じものが二重に定義されている」状態が起きやすい。このスキルはそれを洗い出す。

標準の `/doctor`（インストールの状態・壊れた設定ファイル・使われていない拡張機能などの点検）とは対象が違う。設定ファイルが壊れていないかではなく、読み込まれた設定どうしがぶつかっていないか、権限ルールが書き方の誤りで意図したコマンドに一致しなくなっていないかを見る。
