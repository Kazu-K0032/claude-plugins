# 既存の Terraform の構成に合わせる

`terraform` の手順 4 で、`.tf` が既にある（状態 B）ときに使う。ファイルは動かさず、コピーした規約のほうを今の構成に合わせる。

## 規約のパスを書き換える

コピーした `.claude/rules/terraform.md` の、次の箇所を今の構成の場所に書き換える。

- frontmatter の `paths`
- 冒頭の固有の値の表
- 「ファイルを置く場合」の表
- `infra/` で始まるパス

## 規約と違う点の扱いを聞く

今の構成が規約と違う点（workspace で環境を分けている・ファイルの分け方が違うなど）は一覧にし、`AskUserQuestion` で扱いを聞く。`.tf` は変えない。

| 選択肢 | 扱い |
| --- | --- |
| 規約を今の構成に合わせる | 規約の該当の行を、今の構成の書き方に書き換える |
| 規約のまま残す | 規約は変えず、構成を直すかは手順 9 で利用者に任せる |
