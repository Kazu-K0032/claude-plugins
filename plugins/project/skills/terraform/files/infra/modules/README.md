# modules

## このディレクトリは何か

環境をまたいで使う部品（モジュール）を置く場所。`environments/<環境>/main.tf` から呼ぶ。

## いつ読むか

- リソースを足すとき（既存のモジュールに入れるか、新しく作るかを決める）
- ある機能が、どのモジュールにあるかを探すとき
