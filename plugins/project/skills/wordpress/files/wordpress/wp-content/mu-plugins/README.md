# mu-plugins

## このディレクトリは何か

テーマを替えても残す処理（投稿タイプ・タクソノミーの登録、サイト固有の処理）を置く場所。ここに置いたファイルは、WordPress が自動で有効にする。

## いつ読むか

- 投稿タイプ・タクソノミー・カスタムフィールドを足す・直すとき
- サイト固有の処理が、どのファイルにあるかを探すとき
