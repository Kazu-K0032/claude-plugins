# 衝突したファイルのマージ方針

`gas` の手順 5 で、`DIFF` のファイルがあるとき、上書き / 手でマージ / 据え置きを選んでもらう前に読む。ファイルごとの「上書きしない」「既存を正とする」は、選択肢を示すときに伝える。

| ファイル | マージ方針 |
| --- | --- |
| `src/appsscript.json` | 既存を正とする。`oauthScopes`・`dependencies`・`webapp` などの既存のキーは消さない。`timeZone`・`runtimeVersion` が違う場合は、変えるかを確認するだけにする |
| `.clasp.json` | 既存を正とする。`scriptId` は残し、`rootDir` は手順 3 で直した値（方針 A）か既存の値（方針 B。手順 1 で絶対パスを直すことにした場合は直した値）にする |
| `src/*.js` | 既存のコードを捨てない。上書きせず、手順 6 の振り分けで扱う |
| `.claude/rules/gas.md`・`.claude/rules/gas-runtime.md` | 既存の規約に足りない項目だけを足す。導入済みの `gas.md` が 1 ファイル版なら、下の「古い 1 ファイル版の片付け」も行う |

## 古い 1 ファイル版の片付け

規約は、前は `gas.md` の 1 ファイルだった。今は、実行時間とトリガーの節を `gas-runtime.md` に分けている。導入済みの `gas.md` に次の節があれば、1 ファイル版として扱う。

| 古い `gas.md` の節 | 移した先（`gas-runtime.md`） |
| --- | --- |
| 実行時間の上限を前提に作る | 時間のかかる処理を書く場合 |
| トリガーは登録用の関数から作る | トリガーを作る・変える場合 |

- `gas-runtime.md` は新しいファイルとして入るため、`既存は置き換えない` のときも、同じ規則が 2 つのファイルに残る。`DIFF` の選択肢を示す前に、このことを伝える
- 移した節を `gas.md` から消すかを、利用者に聞く。残すと、片方だけ直したときに規則が食い違うため
- 消すと決まったら、`Edit` で節を消す。利用先が行を足していれば、消す前に `gas-runtime.md` へ移すかを聞く
- 節の名前が変わっていて見つけられないときは、消さずに、重なっていそうな節を示して利用者に任せる
