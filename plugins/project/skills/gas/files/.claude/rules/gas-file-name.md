# GAS の入口のファイルの名前に関するルール

入口のファイル（`_main.js`）の名前の付け方を決める。Apps Script のエディタで、入口をファイルの一覧の先頭に並べて探しやすくするため。ほかのファイルの名前は `.claude/rules/gas.md` にある。

## 入口のファイルに名前を付ける場合

- 入口のファイルだけは、名前の先頭に `_` を付けて `_main.js` にする。名前順に並ぶと、`_` で始まる名前は、機能を表す小文字の名前より先に並ぶため
- ほかのファイルには、先頭に `_` を付けない。先頭に並ぶのは、入口だけにするため
- 関数名の末尾の `_`（`gas.md` の「関数に名前を付ける場合」）とは別の決まり。ファイル名の `_` は、関数の呼び出しや、トリガーの登録には影響しない
- ファイル名を変えたときは、そのファイル名を書いた文書（規約・README・手順書）とコメント（`trigger.js` など）も直す
- 反映した後は、エディタで入口が先頭に並ぶかを確かめる。エディタの並び順は、公式の文書で確かめられていないため
