# GAS のシートの見た目に関するルール

GAS でスプレッドシートのタブ（シート）を作る・書き換えるときの書式（フォント・色・枠線・文字の位置）を決める。タブを作るたびに書式を決め直さず、どのシートも同じ見た目で読めるようにするため。コードの置き場所と命名は `.claude/rules/gas.md`、実行時間の決まりは `.claude/rules/gas-runtime.md` にある。

## 見た目を決める場合

利用先に見た目の決まり（既存のシート・手本にするシート・規約）があれば、それに合わせる。無いときだけ、次の標準を使う。

| 項目 | 標準 |
| --- | --- |
| フォント | メイリオ。見出し行は 11pt、本文は 10pt |
| 見出し行 | 太字、塗りは薄い灰色（`#f3f3f3`）、文字の位置は中央寄せ |
| 枠線 | すべてのセルに、細い灰色（`#cccccc`）の実線を付ける |
| 固定 | 1 行目だけを固定する |

## 文字の位置を決める場合

列の種類で決める。種類が同じ列の位置がそろい、値を見比べやすくなるため。

| 列の種類 | 位置 |
| --- | --- |
| 文（名前・メモ・URL など） | 左寄せ |
| 日付・日時 | 中央寄せ |
| 数 | 中央寄せ |
| チェックボックス | 中央寄せ |

## 書式を設定する場合

- 書式の値（フォント名・色・サイズ）は `constants.js` に、書式を当てる関数はスプレッドシートのサービスのファイル（例：`spreadsheet.js`）に置く。複数のタブで使うため、機能ごとに書くとタブごとに見た目がずれる
- 書式は、範囲全体にまとめて設定する。セルごとに呼ぶと、実行時間の上限に近づくため（`gas-runtime.md` の「時間のかかる処理を書く場合」）
- 既存のタブの書式は、承認なしに変えない。利用者が手で整えた見た目を、知らないうちに変えないため
