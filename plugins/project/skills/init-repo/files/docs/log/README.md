# log

## このディレクトリは何か

実作業の経緯を、時系列で残す場所。何をして、何が起き、どう判断したかを書き、後任が経緯をたどって引き継げるようにする。

## いつ読むか

- 作業を引き継ぐとき
- 障害や問題が、前にも起きていないかを確かめるとき
- ADR の「経緯の記録」から、判断のきっかけをたどるとき

## 書き方

- ファイル名は `YYYY-MM-DD-<作業の対象>.md`。同じ日に別の作業をしたら、ファイルを分ける
- ログを足したら、上の表に 1 行足す
- 手順そのものは書かない。手順は `runbook/` に書き、ここからリンクする
- 判断の結果は ADR（`adr/`）に書き、ここからリンクする。ここに残すのは、判断に至った経緯だけ
