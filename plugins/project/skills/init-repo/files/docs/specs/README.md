# specs

## このディレクトリは何か

何を作るかを書く場所。機能要件・非機能要件・スコープ（やらないこと）を置く。どう作るかは `architecture/`、なぜそう決めたかは `adr/` に分け、ここからはリンクで指す。

## いつ読むか

- 要件を確かめたいとき
- 新しい機能を足す前（スコープの中かを確かめるため）
- スコープ外の項目を確かめたいとき

## 文書一覧

| ファイル | 内容 |
| --- | --- |
| [specifications.template.md](specifications.template.md) | 要件定義書の雛形（概要・ゴール・成功指標・機能要件・非機能要件・制約）。実物は `specifications.md` |

## 書き方

- 実物は `specifications.md` の 1 ファイルに、機能要件と非機能要件をまとめる。収まらなくなったら、領域ごとに別のファイルへ分け、上の表に足す
- 要件の状態は、✅（確定）・🔶（目安として設定）・❓（要確認）の 3 つで示す
- 実物を作ったら、上の表を実物の行に差し替え、雛形の削除を利用者に提案する（手順は [docs/README.md](../README.md) の「雛形から実物を作るとき」）
