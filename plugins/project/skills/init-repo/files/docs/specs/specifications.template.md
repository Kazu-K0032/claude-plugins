このプロジェクトで確定している要件と、それを満たすための非機能要件を書く。[例: 〇〇のために、〇〇を作る]

- 機能要件は、何を作るかを決める軽量な PRD（プロダクト要求仕様書）の形で書く
- 非機能要件は、可用性・性能・運用保守・移行・セキュリティ・システム環境の 6 項目のチェックリストで書く

## 凡例

- ✅: 確定している要件
- 🔶: 確定していないが、一般的な目安として設定しているもの
- ❓: 確定しておらず、要確認の要件
