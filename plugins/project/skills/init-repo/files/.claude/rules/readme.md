# README.md に関するルール

README.md を、情報の原本ではなく他の文書への入り口（案内板）として書くための、役割・種別・構成・更新の決まりを決める。本文を再掲せずリンクだけを持たせ、SSOT（唯一の情報源）と食い違わないようにするため。README.md について、ほかの文書の規約と競合する場合は、このファイルを優先する。ほかに文書の規約が無ければ、このファイルだけに従う。

## README.md を書く場合

- README.md は「案内板」であり、情報の原本ではなく **リンクの集約点**。他ドキュメントへの入り口を示すことが唯一の責務
- README.md に情報の本文を書かない。他ドキュメントへのリンクで代替する
- H1 は 1 つのみ。ディレクトリ名またはプロジェクト名を使う
- 相対パスリンクのみ使う（絶対パス禁止）
- 各階層の README.md は案内板として配置するため SSOT の対象外とする。案内板は、他ファイルの内容を要約せず、リンクで案内するだけなので、重複記述としては扱わない。他ドキュメントへのリンクのみを保持し、本文を再掲しないことで SSOT との矛盾を解消する

## README.md を置かない場合・この規約の対象外

- `.claude/` 配下には README.md を追加しない。`.claude/` 内のファイルは AI 向けの設定・定義ドキュメントのため
- `node_modules/` など `.gitignore` で管理されるディレクトリは、この規約の対象外

## README.md の種別

| 種別 | 対象 | 役割 |
| --- | --- | --- |
| プロジェクトエントリポイント | `README.md`（リポジトリルート） | プロジェクト全体の入口。直下の各サブツリーのエントリポイント README へ案内する |
| サブツリーエントリポイント | 各サブツリー直下の `README.md` | そのサブツリーの入口。配下の README を案内する |
| 案内板型 | `docs/**/README.md` など | そのディレクトリの責務とファイル一覧を示す |

## 下の階層へ案内する場合

README は自分のサブツリー直下の README だけを案内する。サブツリーをまたいで下層の個別 README を直接リンクしない。

- ルート `README.md` が案内するのは各サブツリーのエントリポイント（`docs/README.md` 等）まで
- サブツリー配下に個別 README を追加する場合は、そのサブツリーのエントリポイントから辿れるようにする
- 下層 README をルート `README.md` から直接案内しない。案内責務を各エントリポイントに局所化し、階層を飛ばさないため

## 案内板型 README.md の構成

### 必須セクション（この順序で配置）

`## このディレクトリは何か` → `## いつ読むか` の順序を変えない。

1. `## このディレクトリは何か` — 責務を 1〜2 文で定義（「〜を書く場所」の形式）
1. `## いつ読むか` — 使用シーンを箇条書き
1. `## ファイル一覧` / `## 文書一覧` / `## モジュール一覧` / `## ADR 一覧` — ディレクトリの内容に合わせた名称。相対パスリンク付きテーブル

### 任意セクション（必須セクションの後に置く）

- `## 書き方` — ファイル追加ルールがある場合（例: ADR の命名規則）
- `## Reading Path` / `## 役割別の入り口` — `docs/README.md` のような上位案内板のみ
- `## 〇〇との違い` — 隣接ディレクトリと混同されやすい場合

### テーブル列名の標準

テーブルは標準列名を使う。

| ディレクトリの性質 | 列構成 |
| --- | --- |
| ドキュメント群 | `ファイル \| 内容` |
| サブディレクトリ群（`docs/README.md` 等） | `ディレクトリ \| 内容` |
| 機能モジュール群 | `モジュール \| 役割` |
| データファイル群 | `ファイル \| 内容 \| 備考` |
| ADR（`docs/adr/`） | `日付 \| 題 \| 状態` |

## ルート README.md の構成

案内板型とは別規約。プロジェクト全体の入口として機能する。構成はリポジトリの `README.md` を正とする。

## ファイルを足す・変える場合

案内板型 README.md は、次のときに更新する。

| タイミング | 対応 |
| --- | --- |
| ディレクトリにファイルを追加したとき | ファイル一覧テーブルに行を追加 |
| ファイルを削除・改名したとき | テーブルの該当行を更新・削除 |
| ディレクトリ責務が変わったとき | `## このディレクトリは何か` を更新 |

ルート README.md は、次のときに更新する。

| タイミング | 対応 |
| --- | --- |
| ルート直下に、README を持つディレクトリ（サブツリー）を追加したとき | そのエントリポイント README へのリンクを追加 |
| 公開 URL が変わったとき | 環境リンクの表を更新 |
| プロジェクト構成方針に大きな変更があったとき | ADR 発行と連動して更新 |

**更新不要なケース**: 既存ファイルの内容のみ修正したとき（ファイル名が変わらなければリンクは生きている）。`docs/` 配下に文書やサブディレクトリを追加したとき（`docs/README.md` を更新する）
