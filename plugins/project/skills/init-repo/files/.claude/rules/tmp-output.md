# `tmp/` への出力に関するルール

このリポジトリでは、Claude が作るレポート・下書き・作業ファイルを `tmp/<ブランチ名>/` に置く。`tmp/` は `.gitignore` に入っていて、コミットに混ざらない。削除は人が行うため、置くものの種類ごとに場所を分け、人がどれを消してよいか見分けやすくする。

## ブランチごとのフォルダを決める場合

- フォルダ名は、ブランチ名の `/` を `-` に置き換えたものにする（例：`issues/5-sample` → `tmp/issues-5-sample/`）

## 作業用のファイルを作る場合

- スクリプト・中間ファイル・確認用の画像は、`tmp/<ブランチ名>/work/<目的>/` に置く。`<目的>` には、作業の中身が分かる英語の短い名前を付ける（例：`merge-conflict`・`image-check`）
- 同じ作業のファイルは、同じ `<目的>` のフォルダにまとめる。人が作業の単位でまとめて消せるようにするため
- 作ったファイルは消さない。片付けは人が行う
- Python のスクリプトは、`python -B <ファイル>` のように `-B` を付けて実行する。付けないと、読み込んだファイルの `.pyc` が `__pycache__` に残り、消せないファイルが増えるため

## スキルの出力を書く場合

- スキルの出力は、そのスキルの決まりの場所に書く。`work/` には置かない
- 1 回の実行で同じ種類のファイルを何度も書き出すスキル（`issue-start`・`issue-pr-sync`・`commit`）は、`tmp/<ブランチ名>/<スキル名>/` にまとめる
- それ以外のスキルは、`tmp/<ブランチ名>/` の直下に書く
