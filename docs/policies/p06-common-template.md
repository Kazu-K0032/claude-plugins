# P6 共通のテンプレートには、どのプロジェクトでも使うものだけを入れること

| 区分 | 内容 |
| --- | --- |
| 対象 | `project`（`init-repo`・`gas`） |

`init-repo` のテンプレートには、どのプロジェクトでも使うものだけを入れる。技術やプロジェクトで変わるもの（言語別のルール・ビルドの CI など）は配らず、README の「除外したもの」に理由を書く。別のスキルがそのファイルを作るときは、その理由と食い違わないかを確かめる。

## 理由

- 【使い回し】技術やプロジェクトで変わるものを共通のテンプレートに入れると、多くのリポジトリで書き換えや削除が要るから
- 【判断の一貫性】配らないと決めた理由が、別のスキルで知らないうちに崩れないようにしたいから

## Q&A

### Q. `init-repo` が配らないファイル（例：ビルドの CI）を、別のスキルで作りたい

`init-repo`・`gas` の README の「除外したもの」で理由を読み、食い違わないかを確かめる。言語別のルールは「技術によって違う」ため除外しているので、技術別のスキルが配るのは理由に合っている。

### Q. 除外した理由と食い違う

作る前に利用者に伝え、除外をやめるか、作るのをやめるかを選んでもらう。除外をやめるなら、README の「除外したもの」の表から消す。
