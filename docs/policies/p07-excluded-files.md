# P7 除外したものを作るときは除外の理由を確かめること

`init-repo`・`gas` の README の「除外したもの」には、わざと配らないファイルとその理由を書いている。別のスキルがそのファイルを作るときは、その理由と食い違わないかを確かめる。

## 理由

決めた理由が、別の場所で知らないうちに崩れないようにするため。

## 対象と例外

- 対象：`project`
- 例：「言語別の実装ルール」は、採用する技術によって違うため `init-repo` では配らない。`gas` が GAS 用のルールを配るのは、この理由に合っている

## Q&A

### Q. `init-repo` が配らないファイル（例：ビルドの CI）を、別のスキルで作りたい

`init-repo`・`gas` の README の「除外したもの」で理由を読み、食い違わないかを確かめる。言語別のルールは「技術によって違う」ため除外しているので、技術別のスキルが配るのは理由に合っている。

### Q. 除外した理由と食い違う

作る前に利用者に伝え、除外をやめるか、作るのをやめるかを選んでもらう。除外をやめるなら、README の「除外したもの」の表から消す。
