# P5 常に効かせたい規約はリポジトリへコピーして配ること

常に効かせたい規約は、スキルが導入先の `.claude/rules/` へコピーする。スキルの実行中にだけ使う判断基準は、プラグインの `references/` に置く。

## 理由

プラグインの仕組みでは `.claude/rules/` を配れないため。コピーされた規約は、プラグインの有無に関係なく効く。

## 対象と例外

- 対象：`project`（`init-repo`・`gas`）

## 変えたいとき

- コピーした規約は、プラグインを更新しても書き換わらない。新しい規約を取り込むときは、スキル（`/project:init-repo` など）をもう一度実行し、差分を確かめる

## Q&A

### Q. 判断基準を、`references/` と `.claude/rules/` のどちらに置く？

スキルの実行中だけ使うなら、プラグインの `references/` に置く。スキルを使っていないときも効かせたいなら、テンプレートの `.claude/rules/` に置き、スキルでコピーする。

### Q. 配った規約を直した。利用先にも届けたい

自動では届かない。PR の「利用先への影響」に、スキルを再実行すれば差分を取り込めることを書く。
