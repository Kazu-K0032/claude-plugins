# V3 何を作るかと、これで良いかの判断は、人が持つこと

AI に任せるのは作業まで。何を作るかを決めることと、できたものをこれで良いと判断することは、人が手放さない。

## 理由

- 【責任】AI は出力に責任を負わない。障害や権利の侵害が起きたとき、説明するのは受け入れた人だから
- 【影響】マージやリリースのように、ほかの人やサービスに効く判断は、取り消しにくいから

## プラグインでの表れ

- `aidd:commit` はコミットメッセージを `tmp.md` に書くだけで、コミットと push は人が行う
- `aidd:issue-start` は、計画を人が承認してから実装に進む
