# V4 ADR などの判断の記録で、人がいなくても知識を受け継げるようにすること

なぜその選択をしたかを、ADR・ルール・`CLAUDE.md` に残す。目的は AI の実装の精度を上げることではなく、判断した人がいなくなっても、文書が知識を次の人へ受け継ぐ状態をつくることにある。

## 理由

- 判断が成文化されていれば、人に依存せず、プロジェクトを次の人へ受け継いでいけるから
- 理由が残っていないと、後任が過去の判断を分からないまま受け入れるか、知らずに覆すかのどちらかになるから
- ADR を AI に読ませても、新しく実装するときの精度はほとんど変わらない。AI が役立つのは、既存のコードを変えるときに「過去の ADR では〇〇の判断でこの選択をしたが、考慮されているか」と指摘する場面くらいで、主な読み手は後から来た人だから

## プラグインでの表れ

- `aidd:adr` は、理由をコードのコメントに書けない判断を残し、`project:init-repo` が配る `CLAUDE.md` で一覧を毎回読み込む
- このリポジトリの方針は、1 つずつ理由と Q&A を付けて残す
