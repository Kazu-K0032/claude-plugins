# V1 作業時間の短縮ではなく、成果物の質と量を高めること

AI が作業を担って空いた時間は、仕様・設計・熟読・ドキュメントに注ぐ。短縮は目的にせず、質を追った結果として付いてくるものとする。

## 理由

- 【出戻り】確かめる手間を削ると、仕様の解釈違いや不具合が後で見つかり、書いた直後より直すのに時間がかかるから
- 【負債】理解していない実装の上に次を積むと、着手のたびに読み直しが要り、全体としては速くならないから

## プラグインでの表れ

- `aidd:issue-start` は、実装の前に計画モードで、何を作るかを質問で詰める
- `aidd:pr-create` は、レビュワーが自分の手で確かめる検証コメントを作る
