# V2 AI の出力は、説明できるまで理解してから受け入れること

AI が書いたコードや文書は、なぜそうなっているかを自分で説明できるまで読んでから受け入れる。

## 理由

- 【知見】AI に任せた調査・記述・実装は、もとは理解が貯まる工程だった。通すだけでは、自分の中に何も残らないから
- 【負債】理解せずに通した出力は、後から別のタスクとして積み上がるから

## プラグインでの表れ

- `aidd:pr-review` は、レポートを `tmp/` に出すだけで PR に投稿しない。指摘の採否は、人が読んで決める
- `aidd:docs-sync` は、直すべき文書を挙げるだけで、自動では直さない
